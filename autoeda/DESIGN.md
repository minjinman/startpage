# 설계 메모 (자체 검증으로 수정된 사항 포함)

## 구조
`load(+정제) → 타입 추론 → 종류 판별 → plan_analysis(계획) → run(실행) → 리포트(HTML) / brief(md)`

- 계획과 실행을 분리해 노트북에서 계획을 보고 고칠 수 있게 했다(`plan.drop`, `set_param`).
- 한 단계가 실패해도 나머지는 실행하고, 실패/미구현/제외 항목은 리포트의 "분석하지 못한 항목"에 사유와 함께 남긴다.

## 자체 검증에서 반영한 수정
| 문제 | 반영 |
|---|---|
| 실제 데이터 정제 단계 누락 | `loader.py`: 결측 표기·숫자/날짜 문자열·앞자리 0·엑셀 헤더, 변경 내역을 로그로 공개 |
| 타깃 자동 추정 위험 | 추정하지 않음. 미지정 시 탐색 분석만 |
| 모델 검증 방식 | P2에서 시간 분할/GroupKFold/불균형 지표를 규정 후 구현 |
| Cpk 오용 위험 | P4에서 관리도로 안정성 확인 후에만 계산 |
| 규칙 허점(리커트·lot·ID) | 문자열 척도 매핑, 단어 경계 매칭, ID 최소 표본, 모두 '의심'+근거 표시, `types=` 덮어쓰기 |
| 상관의 과다 유의 | 효과크기 기준(|ρ|≥0.3) + FDR, 상위 N개만 표시, 혼합 타입은 V/ε² |
| 정규성 검정 후 검정법 선택 | 비모수(스피어만/크러스칼-월리스)를 기본으로 하고 효과크기 병기 |
| 시계열 p값 낙관 | 날짜 컬럼이 있으면 경고 |
| 핵심 발견 선정 기준 부재 | 효과크기 × √(n/100) 점수, 단계당 2개 상한 |
| brief 프라이버시 | 범주값 생략, 최솟값/최댓값 제외, `anonymize=True` 별칭(별칭표는 별도 파일) |
| 재현성 | 시드·버전·재현 코드를 부록에 기록 |
| API 설계 | `plan_analysis → run`, `analyze` 는 단축 |
| `goal` 키워드 | 제거(구조화 인자만) |

## 테스트 전략
합성 데이터는 순환 검증이라 **외부 기준점**을 쓴다: scipy/statsmodels 직접 호출 결과와의 일치(스피어만 p, FDR),
공개 데이터셋(와인)에서 알려진 구조(flavanoids↔품종) 재현, 실제 데이터는 받는 대로 추가.


## 구현 중 발견·수정한 문제 (테스트가 느슨해서 놓칠 뻔한 것들 포함)
| 문제 | 수정 |
|---|---|
| 시계열: 긴 계절 주기가 짧은 주기를 흡수해 168칸(주간)이 선택되고 잔차가 과적합 | 강도가 비슷하면 **더 짧은 주기** 선택 |
| 이상구간: 로버스트 STL 잔차는 꼬리가 무거워 순수 잡음에서도 오탐 다수 | 비로버스트 STL 잔차 + **반복 클리핑**, 임계값을 잡음 시뮬레이션으로 보정(오탐 ≈0.1점/720) |
| 변화점: 추세 램프·랜덤워크를 변화점으로 오인 | 선형추세가 더 잘 설명하면 폐기, 잔차 자기상관이 높으면(랜덤워크) 폐기 |
| 변화점: 변화 자체가 분산 추정을 부풀려 자신을 가림(관리도 로트 이동 미탐지) | 후보 분할을 먼저 구하고 **분할 평균을 뺀 잔차**로 장기분산 추정 |
| 안정성 판정: 'R1 0개 요구'는 점이 100개면 안정 공정의 24%를 불안정으로 판정 | 우연 신호 수의 **포아송 분위수까지 허용**(오판정 ≈2%) |
| 설문 감지: 끝 단계를 안 쓰는 문항은 척도 범위가 달라 미감지 | 1~5/1~7 등 **척도 후보 안에 들어가는지**로 판정 |
| 시계열 수준 상관이 핵심 발견 상위에 노출 / 설문 문항 간 상관이 노출 | 시계열은 감점, 설문 문항끼리는 제외 |
| 차트 색을 임의로 골라 색각이상 검증 실패 | 검증된 팔레트(파랑/주황) + 위반점은 색+모양, 발산형은 중앙 회색 |
| 타깃 관련 발견이 공통 단계와 중복 | 타깃 포함 공통 발견은 핵심 발견에서 제외 |
