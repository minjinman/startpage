# autoeda — 자동 데이터 분석 (한국어 HTML 리포트)

데이터(CSV/Excel/DataFrame)를 넣으면 **컬럼 타입과 데이터 종류를 판별해 분석 계획을 세우고, 실행한 뒤, 한국어 HTML 리포트**를 만듭니다.
API 비용이 없습니다(모든 계산은 로컬, 판단은 규칙 기반). 데이터 종류(일반·타깃·시계열·설문·공정)를 판별해 해당하는 분석을 모두 수행합니다.

## 설치 (로컬 Jupyter)

```bash
cd autoeda
pip install -r requirements.txt
pip install -e .          # 어느 폴더의 노트북에서든 import autoeda 가능
```

## 사용법

```python
from autoeda import analyze, plan_analysis

report = analyze("data.csv")                 # 한 번에
report.show()                                # 노트북에서 바로 보기
report.to_html("report.html")                # 단일 HTML 파일(차트 포함)

# 계획을 먼저 보고 고치고 싶을 때
plan = plan_analysis("data.csv", group="라인", types={"공정코드": "categorical"})
plan                                         # 가정, 단계, 이유 확인
plan.drop("outliers").set_param("group_numeric", group="설비")
report = plan.run()

# Claude 채팅(Pro)에 붙여넣어 해석받기 위한 요약 (원본 값 없음)
report.to_brief("llm_brief.md", anonymize=True)   # 별칭표는 llm_brief_aliases.tsv 로 따로 저장
```

| 인자 | 의미 |
|---|---|
| `target` | 설명/예측하려는 컬럼. **자동 추정하지 않음.** 지정하면 타깃 분석(P2) 수행 |
| `task` | `'classification'`/`'regression'`. 자동 판정(범주형·이진값=분류, 그 외 수치=회귀)을 덮어씀 |
| `entity` | 여러 라인·설비가 한 파일에 섞인 시계열에서 개체를 구분하는 컬럼(미지정 시 자동 추정) |
| `lot` | 공정 데이터의 로트/배치(부분군) 컬럼(미지정 시 컬럼명에서 추정) |
| `spec` | 공정 규격 `{"측정컬럼": (하한, 상한)}` (한쪽만 있으면 `None`). 미지정 시 상한/하한/USL/LSL 컬럼에서 추정 |
| `groups` | 같은 대상(설비·로트·사람)이 반복 측정된 경우 교차검증에서 묶을 컬럼 |
| `time` | 시간 컬럼. 없으면 날짜형 컬럼에서 추정 |
| `group` | 집단 비교 기준 컬럼 |
| `types` | `{"컬럼": "numeric/categorical/datetime/id/text/exclude"}` 로 자동 판정을 덮어씀 |
| `sheet` | 엑셀 시트 이름(기본: 첫 시트) |

## 무엇을 하나 (P1)

1. **로드·정제**: 인코딩 자동 감지(UTF-8/CP949), `-`/`N/A` 등 결측 표기, `1,234`·`95%` 숫자 변환, `2024.01.05`·`오전/오후` 날짜, 앞자리 0 코드 보존, 엑셀 상단 제목 행 건너뛰기. **바꾼 내용은 전부 리포트에 기록**하고 원본은 건드리지 않습니다.
2. **판별**: 컬럼 타입(수치/범주/날짜/ID/상수/텍스트)과 데이터 종류(시계열·설문·공정 의심)를 근거와 함께 표시.
3. **공통 분석**: 결측·중복, 이상치(IQR), 분포, 수치 상관(스피어만), 범주 연관성(Cramér's V), 집단별 수치 차이(크러스칼-월리스).
4. **검증 장치**: 다중비교 FDR 보정, 효과크기 기준, 최소 표본 수 가드, 중복 컬럼 의심 경고, 시계열 자기상관 경고, "분석하지 못한 항목" 명시, 시드·버전 기록.

## 타깃 분석 (P2) — `target=` 을 지정했을 때

- **타깃 개요**: 클래스 분포/불균형, 수치 타깃 분포·왜도, 결측.
- **변수별 단변량 관계**: 분류는 크러스칼-월리스(ε²)/Cramér's V, 회귀는 스피어만/크러스칼-월리스. FDR 보정 + 효과크기 기준.
- **예측 평가**: 기준선(학습 없음) vs 선형 모델 vs 그래디언트 부스팅을 교차검증으로 비교. 전처리는 폴드 안에서만 학습해 누수를 막음.
  - 분할은 구조에 맞춤: 시간 컬럼이 있으면 **시간순**, `groups=`(또는 감지된 로트)가 있으면 **GroupKFold**, 그 외 층화/일반 KFold.
  - **기준선과 차이가 없으면 "예측력이 없다"고 보고**합니다.
- **누수 점검**: 변수 1개만으로 거의 완벽히 맞는 변수를 표시하고, 그 변수를 뺀 성능을 함께 보여줌.
- **순열 중요도**: 검증 구간에서 계산(폴드 간 일관성 표시). 인과가 아님.

## 시계열 분석 (P3) — 날짜 컬럼이 있을 때 자동

- **구조 점검**: 간격 규칙성, 누락 구간(격자 결측), 같은 시각 중복 → 여러 라인/설비가 섞인 **패널 데이터**면 개체 컬럼을 찾아 개체별로 분석(못 찾으면 시각별 평균으로 합치고 경고).
- **추세**: Theil–Sen 기울기 + **자기상관을 반영해 넓힌 신뢰구간**(표준편차 대비 변화량도 표시).
- **계절성**: 자연 주기(일·주·연) 후보를 STL로 평가해 강도 표시. 긴 주기가 짧은 주기를 흡수하므로 **강도가 비슷하면 더 짧은 주기를 선택**.
- **정상성**: ADF + KPSS를 함께 해석(정상 / 비정상 / 추세정상·구조변화 / 불확실).
- **이상구간**: 시리즈 성격별 기준(계절성 있음=STL 잔차, 정상=이동중앙값 잔차, 비정상=한 칸 변화량). 순수 잡음에서 오탐이 거의 없도록 시뮬레이션으로 보정했고, 이상 판정이 10%를 넘으면 개별 보고하지 않음.
- **변화점**: 자기상관을 반영한 보수적 평균 변화 탐지. **선형 추세나 랜덤워크로 설명되면 변화점으로 보지 않음.**
- **수준 vs 차분 상관**: 공통 추세 때문에 생기는 가짜 상관을 표시.

## 설문 분석 (P4) — 리커트 문항이 3개 이상 감지될 때

- **문항 분포·응답 품질**: 응답 단계별 분포(단일 색상 명도 순서 막대), 천장/바닥 효과, **일률 응답(모든 문항 같은 값) 비율**. 문자열 척도("그렇다" 등)는 숫자로 매핑.
- **신뢰도**: 크론바흐 α + 부트스트랩 신뢰구간, 문항별 "빼면 α", **역문항 자동 의심**(문항-전체 상관 < 0 → 뒤집어서 계산하고 뒤집기 전 α도 표시), 상관행렬 고유값으로 **다차원성 점검 → 바리맥스로 하위척도별 α**.
- **집단 비교**: 합산 점수(문항 평균)를 집단별로 비교(크러스칼-월리스 + ε² + FDR). `group=` 을 주면 문항별 차이도 표시.

## 공정 분석 (P4) — 로트/배치·규격 컬럼이 감지되거나 `lot=`/`spec=` 을 줄 때

- **관리도**: 로트가 있으면 X̄-S(군 크기가 달라도 점별 한계), 없으면 I-MR. 판정 규칙 R1/R2/R3/R5.
  **안정성 판정은 안정 공정에서도 우연히 나올 신호 수(포아송 99% 분위수)까지 허용**합니다(점이 많으면 '신호 0개'가 오히려 드물기 때문).
- **공정능력**: Cp/Cpk는 **안정 공정일 때만** 계산하고, 불안정하면 비운 채 전체 변동 기준 Pp/Ppk만 참고용으로 표시. 정규성이 깨지면 비모수 Ppk 병기. 규격을 컬럼명에서 추정하면 "자동추정"으로 표시.
- **로트 간 변동 비중(ICC)**, **평균 이동 시점 추정**(선형 추세·랜덤워크는 변화점으로 보지 않음).
- **불량(0/1) p 관리도**: 로트별 불량률. 로트 간 변동이 이항 변동보다 크면 **Laney p′ 보정** 적용.

## 한계 — 꼭 읽어주세요

- "판단"은 규칙표입니다. 규칙에 없는 데이터는 공통 분석으로 처리됩니다.
- 모든 결과는 **탐색적**입니다. 인과를 증명하지 않으며, 자유 서술 목표는 이해하지 못합니다(구조화된 인자 사용).
- 컬럼명 기반 판정(로트/규격)은 '의심'으로만 표시합니다. 틀리면 `types=`로 바로잡으세요.
- 속성 관리도는 p 관리도만 있습니다(c/u/np 관리도, EWMA/CUSUM 관리도는 없음). 설문의 α는 서수 척도를 피어슨 상관으로 근사합니다(폴리코릭 미지원).
- 엑셀은 한 시트·한 줄 헤더 기준입니다(병합된 다단 헤더는 미지원). 행이 수십만 이상이면 느릴 수 있습니다.
- 차트의 한글은 시스템 폰트(맑은 고딕/AppleGothic/NanumGothic 등)가 필요합니다. 없으면 리포트에 경고가 표시됩니다.
